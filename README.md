# DevSecOps Lab 2: Secrets Detection Practice Repo

This is a small, intentionally vulnerable practice repository for Lab 2.
It contains several leaked secrets -- some visible in current files, and
at least one that was "removed" in a later commit but still exists in
git history. Your job is to find and remediate all of them.

## What This App Does

A tiny placeholder Node.js app that connects to a database and a
third-party API. It doesn't actually run anything meaningful -- the
point of this repo is the secrets hidden in it, not the application
logic itself.
